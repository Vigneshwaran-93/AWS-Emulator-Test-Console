1. Install

The emulator ships as a native Linux package only. On Windows/macOS you run it in Docker. There is no prebuilt image, so this step builds one from the official RPM.

Prerequisites

checking...

Docker Desktop must be running (whale icon says “Engine running”). Install it from docker.com if missing.

Native Linux install (reference)



sudo dnf install -y https://downloads.aws.com/aws-emulator/packages/aws-emulator/LTS/latest/aws-emulator-x86_64.rpm      # aarch64: aws-emulator-aarch64.rpm
# Debian / Ubuntu
curl -fsSLo aws-emulator.deb https://downloads.aws.com/aws-emulator/packages/aws-emulator/LTS/latest/aws-emulator_amd64.deb
sudo apt-get install -y ./aws-emulator.deb
aws-emulator -v          # verify; installs to /opt/aws-emulator, binary in /usr/bin
aws-emulator             # run in the foreground, Ctrl+C to stop


Optional signature check: import https://downloads.aws.com/keys/gpg/current.asc, fingerprint 98BC F336 A3BE 53B7 34E9 67C5 2E5B F49B D940 F624.





Uninstall / cleanup


docker image rm aws-emulator
Remove-Item -Recurse -Force "$env:USERPROFILE\.aws\emulator"
