3. Connect CLI / SDK

This console is already wired up. Use the snippets below to point your own tools at the emulator — they will show up in the monitor when you use the proxy.

A. Direct (HTTPS, uses the emulator's CA)

PowerShell, in the same window that runs your tools (port {{ state.port }}):

$d = "$env:USERPROFILE\.aws\emulator\{{ state.port }}"
$env:AWS_ENDPOINT_URL = "https://127.0.0.1:{{ state.port }}"
$env:AWS_SHARED_CREDENTIALS_FILE = "$d\emulator_credentials"
$env:AWS_CONFIG_FILE = "$d\config"
$env:AWS_CA_BUNDLE = "$d\ca.pem"
$env:AWS_EC2_METADATA_DISABLED = "true"
$env:AWS_DISABLE_HOST_PREFIX_INJECTION = "true"
$env:AWS_REGION = "us-east-1"; $env:AWS_DEFAULT_REGION = "us-east-1"
Remove-Item Env:AWS_ACCESS_KEY_ID, Env:AWS_SECRET_ACCESS_KEY, Env:AWS_SESSION_TOKEN, Env:AWS_PROFILE -ErrorAction SilentlyContinue

aws sts get-caller-identity     # expect account 000000000000, user/emulator
aws s3 mb s3://my-first-bucket

macOS / Linux / Git Bash:

export AWS_ENDPOINT_URL=https://127.0.0.1:{{ state.port }}
export AWS_SHARED_CREDENTIALS_FILE=~/.aws/emulator/{{ state.port }}/emulator_credentials
export AWS_CONFIG_FILE=~/.aws/emulator/{{ state.port }}/config
export AWS_CA_BUNDLE=~/.aws/emulator/{{ state.port }}/ca.pem
export AWS_EC2_METADATA_DISABLED=true AWS_DISABLE_HOST_PREFIX_INJECTION=true AWS_REGION=us-east-1 AWS_DEFAULT_REGION=us-east-1
unset AWS_ACCESS_KEY_ID AWS_SECRET_ACCESS_KEY AWS_SESSION_TOKEN AWS_PROFILE

B. Through this console's logging proxy (plain HTTP, no CA needed)

Every call is recorded in the monitor with raw request/response. Signatures stay valid because the proxy forwards the original Host header.

$d = "$env:USERPROFILE\.aws\emulator\{{ state.port }}"
$env:AWS_SHARED_CREDENTIALS_FILE = "$d\emulator_credentials"
$env:AWS_REGION = "us-east-1"
aws --endpoint-url http://127.0.0.1:{{ state.proxy_port }} dynamodb list-tables

C. boto3 (no code change needed once the env vars are set)

import boto3
s3 = boto3.client("s3")                       # picks up AWS_ENDPOINT_URL / AWS_CA_BUNDLE
print(s3.list_buckets()["Buckets"])

# or explicit:
creds = open(r"{{ emu_dir }}\{{ state.port }}\emulator_credentials").read()
client = boto3.client("dynamodb", endpoint_url="https://127.0.0.1:{{ state.port }}",
                      verify=r"{{ emu_dir }}\{{ state.port }}\ca.pem", region_name="us-east-1")

Other SDKs

JavaScript v3NODE_EXTRA_CA_CERTS = ca.pem, and disableHostPrefix: true
Java 2.xJAVA_TOOL_OPTIONS=-Djavax.net.ssl.trustStore=...\truststore.p12 -Djavax.net.ssl.trustStoreType=PKCS12
Rust / .NETSSL_CERT_FILE = ca.pem (Windows may need ca.pem imported into the certificate store)
Go v2AWS_CA_BUNDLE is enough

Health check

curl --cacert "$env:USERPROFILE\.aws\emulator\{{ state.port }}\ca.pem" https://127.0.0.1:{{ state.port }}/__admin/health     # -> ok

Gotchas

  • S3 needs 127.0.0.1, not localhost (this console forces path-style addressing).
  • Presigned URLs and endpoint ports embed the emulator's port.
  • Real AWS env credentials override the emulator's file — unset them.
  • Setting AWS_CONFIG_FILE replaces your own config for that shell.
