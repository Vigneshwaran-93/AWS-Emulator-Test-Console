2. Run & control

Start and stop the emulator container. Credentials are generated by the emulator on every start and read back from the shared folder.

Options

Default 9297. Ports port+1 .. port+20 are reserved for resource endpoints (databases, WebSocket APIs).
Off = --auth off, accepts unsigned requests and writes no credentials file.
Unchecked passes -t off.
0 = never stop automatically.
Docker --memory; exit code 137 = killed for exceeding it.
